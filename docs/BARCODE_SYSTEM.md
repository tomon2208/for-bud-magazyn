# System kodów

Na MVP kod jest przypisany do lokalizacji/półki.

Przykład:

A-03-02

Kod może być QR lub Code 128.

Telefon:
SKAN → rozpoznanie lokalizacji → wybór operacji.

Nie wymagamy kodu na każdej sztuce materiału.

W przyszłości można dodać kody materiałów lub etykiety dostawcy bez przebudowy podstawowego workflow.
